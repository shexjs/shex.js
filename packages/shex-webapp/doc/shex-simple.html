Create Gist

Create Gist publishes the current schema, data and query map as a github gist (you'll be prompted for a title), opens the new gist in another window (popup blockers permitting; its address is also printed to the browser console), and reloads this page with the gist as its manifest (a permalink to share).

When this page was loaded from a gist's manifest, Update appears beside it and publishes the current state back to that gist (updating needs the gist owner's token).

It needs a github token with "gist" scope, remembered in this browser's localStorage:

  1. get token (github → Settings → Developer settings → Personal access tokens → Tokens (classic))
  2. press [Generate token] and copy it
  3. press Create Gist and paste it into the token prompt.

About shex-simple

shex-simple is a simple RDF validator web application. It accepts a ShEx schema on the left in three forms: Compact Syntax (ShExC), JSON (ShExJ) and RDF/Turtle (ShExR). Data can be provided on the right in Turtle.
