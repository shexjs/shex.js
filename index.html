ShEx.js WebApps

In-browser demos of the shex.js implementation of Shape Expressions. One validator, in two flavors: simple runs validation on the UI thread; worker runs it in a Web Worker so the page stays responsive (and validation can be interrupted). Everything else is a plugin the validator loads by URL (?plugin=<url>, or named by a manifest entry): a module that may install semantic-action extensions for schemas to dispatch, and may add a screen of panes and verbs of its own beside the validator's.

Browsing a clone? The app pages need the webpack bundles in (e.g. the shex-webapp, shexmap and shexreduce bundles, and the WASI one), which aren't checked in on main. Build them with npm ci && npm run webpacks-all, or fetch the last-published ones with npm run webpacks-fetch (tools/sync-webpacks.sh). This notice is stripped from the published page.

ShEx validator

Validate RDF data against a ShEx schema (ShExC, ShExJ or ShExR).

  • shex-simple — single-threaded (textareas)
  • shex-simple?worker=1 — in a Web Worker (textareas)
  • every example at once — one manifest, and each entry brings the plugin it needs

ShExMap plugin

Validate with the Map extension, capture bindings, and materialize them into another RDF graph on a screen of its own. These URLs open the validator with the plugin and its examples loaded.

  • shexmap-simple — single-threaded (textareas)
  • shexmap-worker — in a Web Worker (textareas)

ShExReduce plugin

Validate with the Reduce extension — actions that steer or check a match as it happens — then fold the parse into an AST. The demo manifest's calculator entries show both.

  • shex-simple + ShExReduce — with the calc examples

Semantic-action extensions

Each link opens the validator on one extension's demo manifest; every entry names the plugin it needs, so picking it installs the handler. Pass and fail examples each, appinfo shows what an action recorded.

  • Eval — JavaScript in a semantic action
  • Test — print(o) / fail(…), the suite's probe
  • WASI — WAT compiled in the page, prelude to standalone module
  • Test in wasm — the probe, as hand-written WebAssembly

Write your own

A plugin is one URL: a module that registers what it adds. doc/plugins.md is the contract, and hello-plugin.js is a working one in about forty lines.

  • shex-simple + Hello — the skeleton, loaded
